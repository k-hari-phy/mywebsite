Make sure the repository is pointing to the correct GitHub link on this machine:
-------------------
git remote -v

If you see nothing or it points to an old HTTPS link, update it to use your working SSH connection by running:
--------------------
git remote set-url origin git@github.com:k-hari-phy/------repository-name------.git

Download the exact changes your other machine pushed to GitHub:
-------------------
git pull origin main

-----------------------------------------------------------------------------------
To prevent Dropbox from corrupting your project files, always follow this workflow:
Before you start working on any machine, always run:
-------------------
git pull origin main

When you finish working, always commit and run:
-------------------
git push origin main
-----------------------------------------------------------------------------------

updating the folder:
-------------------
git add .
git commit -m "Describe changes"
git push

status check:
------------------
git status
git remote -v


Jekyll commands:
-----------------
bundle install % if new gem is added delete gemfile.lock file
bundle update % run this if above is not used
bundle exec jekyll serve % runs Jekyll and gives address
